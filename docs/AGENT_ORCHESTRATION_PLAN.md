# Agent Orchestration Plan

Status: Phase 2 merged planning specification; production implementation not approved
Authority: `SNAKES_AND_LADDERS_ENGINEERING_PLAN.md`

## Authority

The active lead owns synthesis and final dispositions. The master plan names Sol for
that role; model labels are role assignments, not evidence that a particular reviewer
actually ran. Reviewers return evidence and do not concurrently edit normative files.
The current Phase 2 merge is a single Codex review and claims no new independent sign-off.

## Workstreams

- Lead architecture: rules, Unity+C# boundaries, synthesis, and dispositions.
- Independent architecture: adversarial contradictions and gate challenge.
- Systems planning: bounded assemblies, adapters, ownership, and dependency direction.
- QA/simulation: determinism, tests, statistics, exploit bots, and acceptance evidence.
- Formatting review: links, terminology, duplicate IDs, and Markdown consistency only.

## Workflow

1. Validate source, repository, instructions, Unity version, C# profile, and platform floor.
2. Run bounded independent reviews with exact evidence citations.
3. Merge through the lead and preserve every finding and decision.
4. Cross-check rules-to-tests, domain/Unity separation, replay, economy, multiplayer authority, safety, and performance evidence.
5. Publish the consolidated report and obtain explicit implementation authorization only after all preceding gates pass.

## Cost controls

Share one source packet, run structural checks before expensive review, use smoke simulations before million-match sweeps, and promote model effort only after recording the failed rubric item.

## Acceptance

Each workstream has a bounded output and rubric, all P0/P1 findings have dispositions, reviewers are named, and authorization remains `CODE WORK NOT APPROVED` until evidence closes every prerequisite.

## Phase 2 delivery contract

Phase 2 in master section 13 is the permanent-specification merge. It is distinct from
build-order item 2 (the C# domain) in section 14. Completion means all six specifications
are reconciled with selected contracts, serious findings have dispositions/owners and
the consolidated report is committed. Phase 3 independent cross-check and Phase 4
technical implementation activation remain separate. Standing owner permission is already
recorded; do not request it again merely because evidence is still missing.

Each future independent review records source commit, reviewed paths, finding IDs,
severity, rule/test references, disposition recommendation and per-gate verdict. Review
contexts must be distinct; lead self-review is not two approvals. Preserve historical
review provenance in PLANNING_GATE_REVIEW.md and report new evidence separately.

Assembly owners: rules owns Domain; application owns Application; AI owns AI;
infrastructure/backend owns Infrastructure; client/accessibility owns Presentation;
simulation owns Simulation; QA owns Tests. The ADR defines the allowed dependencies.
See [Phase 2 report](PHASE_2_REVIEW.md) for the merged result and outstanding work.
